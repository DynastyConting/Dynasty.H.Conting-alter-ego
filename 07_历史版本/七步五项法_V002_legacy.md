# 七步五项法 V-002（历史版本）

**状态：历史保留，不代表当前主架构。**

V-002 于 2026-08-16 形成，核心结构为：

> **定界 → 原始样本 → 分类 → 归因 → 下一动作 → 反馈 → 退出 / 升级**

配套结构：

- 问题五项：状态 / 条件 / 资源 / 约束 / 轨迹；
- 动作五项：结果 / 成本 / 风险 / 信息 / 余地；
- 信息三项：增减量 / 可信度 / 解释性；
- 余地四项：恢复 / 重试 / 换路 / 裕度。
