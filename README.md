# 周承续的副躯体

> 一个用于在认知能力下降、信息不完整、判断困难，或希望降低临场思考负担时，维持思维连续性的外化认知系统。

## 一、项目定位

“副躯体”不是另一个完整的人，也不是替主体宣布真理的机器。它是一套**机械化、权限受限、可逐步扩展的副系统**：

- 在主体状态较差时，尽可能跑通已经外化的判断程序；
- 在主体状态正常时，降低重复思考与程序性判断的负担；
- 处理不了时允许明确返回 UNKNOWN（未知）或“无法处理”；
- 不能因为流程想要“完整”就凭空补答案；
- 最终主权始终属于清醒状态下的主体。

当前目标可压缩为三句：

1. **提高低能力状态下的决策下限；**
2. **降低高能力状态下的认知负担；**
3. **给普通状态一个可依赖、可复现、通常足够可靠的默认路径。**

## 二、系统结构

当前结构不再把所有功能塞进《七步五项法》，而拆为：

- **七步法**：稳定主干；
- **原生工具（Native Tool）**：天然长在某一步下面；
- **跨步骤工具（Cross-Cutting Tool）**：按条件调用，不被单一步骤独占；
- **安全与审结层**：位于七步法之外、但位于副躯体系统之内；
- **网络框架**：描述节点之间的调用、回退、实施与反馈关系。

详见 [`00_总览/副躯体系统架构.md`](00_总览/副躯体系统架构.md)。

## 三、七步法主干

1. **定界**
2. **事实采样**
3. **结构化**
4. **归因**
5. **下一动作**
6. **反馈**
7. **退出 / 升级**

其中第 7 步同时承担循环控制 / 状态转换功能。

详见 [`01_主干/七步法.md`](01_主干/七步法.md)。

## 五、可靠性边界

副躯体区分三类可靠性：

1. **复现可靠性（Replication Reliability）**：是否像主体正常状态下会怎样思考；
2. **决策可靠性（Decision Reliability）**：这套思路在现实中是否通常有效；
3. **安全可靠性（Safety Reliability）**：即使前两项失败，错误是否仍被限制在可承担范围内。

**复现正确不等于现实正确。** 主体与副躯体可能共享同一个稳定盲点，因此“我和它想得一样”不是独立验证。
