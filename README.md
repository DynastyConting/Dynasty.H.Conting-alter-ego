# 周承续的他我（Alter Ego，他我）

> 一个用于维持主体认知连续性、降低判断负担、辅助信息处理与决策审计的外置认知系统（External Cognitive System，外置认知系统）。
>
> “他我”不是单一工具，而是由副躯体承载、副脑扩展认知、副脊椎维持运行逻辑的长期认知外置体系。

## 一、项目定位

“他我”不是主体的替代者，也不是独立人格复制品。它是主体长期构建的外部认知结构，用于在不同状态下提供稳定、可验证、可复现的辅助能力。

核心目标：

1. 提高低能力状态下的决策下限；
2. 降低高能力状态下的重复认知负担；
3. 建立一个可追溯、可审计、可持续迭代的认知外部接口。

## 二、系统层级

当前总架构：

```
周承续的他我
│
└── 副躯体
    │
    ├── 副脑
    │   └── 知识、分析、认知项目
    │
    └── 副脊椎
        └── 七步法（Seven-Step Method，七步法）
```

其中：

- **他我（Alter Ego，他我）**：总项目名称，代表主体与外置认知系统之间的关系；
- **副躯体（Auxiliary Body，辅助躯体）**：整体承载结构；
- **副脑（Auxiliary Brain，辅助大脑）**：知识管理、分析、学习和认知扩展模块；
- **副脊椎（Auxiliary Spine，辅助脊椎）**：保证系统稳定运行的基础方法论与流程框架。

## 三、副脊椎：七步法

七步法作为副躯体的基础运行框架：

1. 定界
2. 事实采样
3. 结构化
4. 归因
5. 下一动作
6. 反馈
7. 退出 / 升级

## 四、副脑项目

副脑包含多个长期认知项目，包括但不限于：

- 知识污染；
- 历史巡游；
- 心智解剖；
- 审美累积；
- 总纲整理。

这些项目用于扩展主体知识、训练判断能力，并通过长期积累形成个人认知体系。

## 五、可靠性原则

他我系统遵循：

1. 权威来源优先（Source of Truth，事实源）；
2. 状态可验证；
3. 过程可追溯；
4. 不允许无依据补全；
5. 不将缓存记忆替代当前事实。

## 六、语言规范

项目以中文为主。专业名词首次出现时采用“中文术语（English Term，英文术语）”形式标注。

## 七、历史

项目由原“周承续的副躯体”扩展而来。原七步五项法仓库名称及 Git 历史保持连续，后续逐步演化为“周承续的他我”总项目。
