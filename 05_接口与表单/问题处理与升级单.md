# 七步法：问题处理与升级单

> 不知道就写 **UNKNOWN（未知）**；没有就写“无”；不适用就写 **NOT APPLICABLE（不适用）**。
>
> **事实与猜测必须分开。**

## ① 定界

| 问题 | 填写 |
|---|---|
| 最后想得到什么结果？ | |
| 愿意花多少时间？ | |
| 愿意花多少钱？ | |
| 愿意承受哪些麻烦、不便或损失？ | |
| 有哪些明确不愿意交换的东西？ | |

## ② 事实采样

这里只写实际观察到、测到、读取到或明确发生的内容。

| 问题 | 填写 |
|---|---|
| 实际发生了什么？ | |
| 有哪些数字、记录、截图、错误提示或其他原始证据？ | |
| 哪些事情可以确认发生过？ | |
| 哪些关键事实目前仍未知？ | |

## ③ 结构化

| 项目 | 核心问题 | 填写 |
|---|---|---|
| 状态 | 现在到底是什么样？ | |
| 条件 | 什么情况下发生、消失、增强、减弱？ | |
| 资源 | 现在有什么可以调用？ | |
| 约束 | 什么边界不能越过？ | |
| 轨迹 | 它是怎样走到现在的？ | |

## ④ 归因

可调用《通用归因候选生成标准 V0.2》。每个搜索域允许返回：

- NOT APPLICABLE：不适用；
- NO FINDING：适用但未发现异常；
- UNKNOWN：未知；
- POSSIBLE：可能；
- SUPPORTED：已有支持；
- CONTRADICTED：与事实冲突；
- EXCLUDED：已排除。
