# 调用与数据流

## 1. 基本数据流

```text
现实问题 / 输入
    ↓
前置安全与路由判断
    ↓
七步法主干
    ↓
下一动作候选
    ↓
后置审结：是否具备实施资格
    ↓
现实行动 / 暂缓 / 退回主体
    ↓
现实反馈
    ↓
重新进入事实采样、结构化、归因或重新定界
```

## 2. 原生工具调用

原生工具由固定步骤默认拥有：

- 结构化 → 结构化模板；
- 归因 → 归因候选生成工具；
- 下一动作 → 下一动作五项；
- 下一动作的信息维度 → 信息三项；
- 下一动作的余地维度 → 余地四项。

## 3. 跨步骤工具调用

U-003 信息五问适合在以下位置调用：

- 外部信息刚进入系统时；
- 事实采样中来源复杂时；
- 结构化时怀疑信息身份被混淆；
- 归因时某条材料承担过高证据权重时。

U-004 灰值判断适合在以下位置调用：

- 结构化时事实是连续、多维或多状态；
- 归因时证据不足但不确定其是否影响当前选择；
- 下一动作前需要判断未知是否跨过决策 / 风险边界。

## 4. 回退与升级

处理不了不是流程失败，而是合法状态。

可以回退到：

- 重新定界；
- 补充事实采样；
- 重新结构化；
- 保留原因未决；
- 等待信息 / 资源；
- 升级给主体或专业主体。

## 5. 自动实施边界

七步法产生“下一动作”不等于自动拥有实施权限。

动作进入现实前仍可经过安全与审结层，检查：

- 风险是否可承受；
- 后果是否可逆；
- 权限是否足够；
- 关键 UNKNOWN 是否跨界；
- 是否需要主体恢复后再决定。
