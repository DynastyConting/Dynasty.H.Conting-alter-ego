# 副躯体系统架构

## 1. 总体结构

副躯体采用模块化结构，而不是把所有工具塞进一个超级流程。

当前架构分为五层：

1. **主干层**：七步法；
2. **原生工具层**：天然隶属于某一步的机械化工具；
3. **跨步骤工具层**：按条件调用、不被单一步骤独占的工具；
4. **安全与审结层**：负责路由、风险边界和实施资格；
5. **现实校准层**：用现实结果、反例、外部证据和长期复盘修正系统。

## 2. 主干层

七步法作为稳定主干：

> 定界 → 事实采样 → 结构化 → 归因 → 下一动作 → 反馈 → 退出 / 升级

七步法负责问题加工，不负责独占所有审计、判断和安全控制功能。

## 3. 原生工具（Native Tool）

原生工具天然长在某一步下面，为该步骤提供默认机械化检查结构。

当前包括：

- 第 3 步结构化 → 结构化模板；
- 第 4 步归因 → 通用归因候选生成标准 V0.2；
- 第 5 步下一动作 → 下一动作五项；
- 下一动作五项之下 → 信息三项、余地四项。

## 4. 跨步骤工具（Cross-Cutting Tool）

跨步骤工具不属于单一步骤，可由多个节点按需要调用。

当前包括：

- U-003 信息五问：信息审计法；
- U-004 灰值判断工具。

## 5. 安全与审结层

安全与审结层位于七步法之外、但位于副躯体系统之内。

它不亲自解决问题，而主要负责：

- 判断问题是否适合交给副躯体处理；
- 选择应调用的模型 / 工具；
- 检查关键未知是否跨过执行边界；
- 判断处理结果是否具有实施资格；
- 无法判断时默认不扩大自动执行权限，并退回主体。

当前只冻结系统位置和职责，不冻结最终字段、顺序和状态命名。

## 6. 三类可靠性

必须区分：

1. **复现可靠性（Replication Reliability）**：副躯体是否像主体正常状态下会怎样思考；
2. **决策可靠性（Decision Reliability）**：这套思路在现实中是否通常有效；
3. **安全可靠性（Safety Reliability）**：即使前两项失败，错误是否仍被限制在可承担范围内。

复现正确不等于现实正确。

## 7. 共模错误

主体与副躯体高度相关，可能共享同一个稳定盲点。因此：

> **“主体恢复后仍然同意副躯体”只能增强复现可靠性，不能自动证明现实正确。**

长期校准必须引入系统外证据：现实结果、反例、独立信息源和长期复盘。

## 8. 递归终止原则

如果安全与审结层本身无法判断是否有资格授权自动执行，不继续无限创建“审计审计器”。

默认行为是：

> **不扩大自动实施权限，退回清醒主体。**
