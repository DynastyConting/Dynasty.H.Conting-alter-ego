# 边界审计与审结层：架构草案

**状态：只冻结架构位置与职责，不冻结正式工具规范。**

## 1. 位置

边界审计 / 审结层位于七步法之外、但位于副躯体系统之内。

它不是新的第 0 步，也不是第 8 步，而是外层控制结构。

## 2. 主要职责

### 前置审查

- 这个问题是否适合交给副躯体处理；
- 应调用七步法还是某个跨步骤工具；
- 当前是否存在必须先补充的信息或权限条件；
- 当前主体状态是否允许某些自动权限。

### 后置审结

- 模型 / 工具已经跑完，但结论是否有资格进入现实实施候选；
- 风险边界是否足够清楚；
- 关键 UNKNOWN 是否可能跨过执行边界；
- 后果是否可逆、可承担；
- 是否必须等待主体恢复后再次判断。

## 3. 授权原则

### 可承受错误

如果副躯体判断错误的后果仍处于预先授权、可逆且可承担的范围内，可允许有限代理。

### 高风险或关键未知

如果存在重大尾部风险、高度不可逆后果，或关键 UNKNOWN 无法证明不会跨过行动边界，则降低或撤销自动执行权限。

### 无法判断

审结层如果无法判断自己是否有资格授权，不继续向上创建无限元审计器。

默认：

> **暂不自动实施，并退回清醒主体。**

正式字段、顺序、状态名、阈值和具体路由逻辑均留待后续专项构建。
