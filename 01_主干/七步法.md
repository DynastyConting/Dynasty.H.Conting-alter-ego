# 七步法

## 0. 定位

七步法是“周承续的副躯体”中的**稳定主干**，不是整个副躯体，也不是所有工具的容器。

当前主干：

> **定界 → 事实采样 → 结构化 → 归因 → 下一动作 → 反馈 → 退出 / 升级**

七步法不保证最优解，也不保证目标一定能实现。它的价值是把一个混乱问题加工成：

- 更接近目标；
- 更容易判断；
- 更容易继续处理；
- 更容易形成低风险下一动作；
- 或更容易升级移交。

## ① 定界

### 定义

明确本轮处理追求的**目标状态**，并记录主体为此愿意接受的**主观交换边界**。

只回答两个问题：

1. **我要把问题推进到什么状态？**
2. **我主观上愿意拿什么来换？**

### 关键边界

- Subjective Exchange Willingness（主观交换意愿）是决策输入，**不等于行动授权**；
- 本步骤不判断现实是否可行、资源是否充足、实际成本、风险、比例性或权限；
- 因此“5 元换 1 克黄金”可以作为目标 / 愿望进入第一步，后续再判定其现实不可行；
- 降级状态下的即时交换意愿，不应自动覆盖清醒状态下已明确的长期边界。

## ② 事实采样

旧名：“原始样本”。

### 定义

在定界后，围绕当前目标收集能够直接观察、读取、测量或取得的证据，并尽量保持其未经解释、未经改写的状态。

### 核心职责

- 回答“现在实际掌握了什么”；
- 记录直接观察、原始记录、测量结果、外部报告和明确未知；
- 尽量把事实与解释分开；
- 不在此步骤做归因、解释、可信度审计或下一动作判断。

事实采样与 U-003 信息五问不同：前者负责“拿进来”，后者负责在必要时判断信息“有多大资格进入判断”。

其中 Information Provenance（信息来源 / 信息溯源）回答的是“这条信息是怎么知道的”，不得与第四步搜索域中的 Input Source（输入来源，即输入对象本身从哪里来）混同。

## ③ 结构化

旧名：“分类”。

### 定义

把事实采样得到的材料，转换成当前执行者可以理解、比较和继续处理的 Problem Representation（问题表征）。

现实本身可能连续、多维、混沌。结构化必然包含抽象、压缩和一定信息损失。目标不是幻想零污染，而是让加工过程：

- 可见；
- 可追溯；
- 可纠正；
- 必要时可以回到事实采样层。

### 原生工具

旧版“状态 / 条件 / 资源 / 约束 / 轨迹”降为结构化步骤下的原生工具。

其中 Current State（当前状态）负责描述“现在是什么样”，Constraints（客观约束）负责记录现实已经存在的边界。它们不直接完成第四步的异常审查或因果搜索。

详见：[`../02_原生工具/结构化模板.md`](../02_原生工具/结构化模板.md)

## ④ 归因

### 当前功能定位

第四步不再要求执行者“聪明地猜出真正原因”。当前黑箱接口进一步收窄为：

> **输入一个已经由前三步形成的 Problem Representation（问题表征），系统扫描若干 Search Domain（搜索域），输出值得继续探索的 Candidate Direction（候选探索方向）。**

它不直接输出：

- 唯一根因；
- 最终解决方案；
- 具体行动授权。

第四步的目标是降低：

- 明显漏项；
- 凭空编因；
- 因为执行者临场能力不足而完全卡死的概率。

### 当前骨架

第四步以已经观察到的 Outcome / Explanandum（结果／待解释项）为解释对象：

- 纵向 Search Domain Axis（搜索域轴）负责反向生成候选因果因素／候选探索方向；
- 横向 Orthogonal Dimensions（正交维度）负责描述、限定和审计候选；
- Taxonomy Gap（分类体系缺口）与 Cause Unresolved（原因未决）保留开放出口。

Output（输出）通常是待解释结果，不单列为一级 Search Domain。

### 通用状态

各搜索域和检查项统一使用四值：

- **是**：该项已完成检查，且存在值得继续探索的偏离／命中；
- **否**：该项已完成检查，未发现值得继续探索的偏离；
- **未知**：该项理论上需要判断，但当前信息不足，或判据尚未建立；
- **不适用**：该项对当前问题没有意义。

**硬约束：每个「是」或「否」之前必须先写判据。**

判据指本轮实际使用的、可观察或可测量的区分条件——阈值、标准、对照、机械检查句、参照状态，四者之一即可。没有写出判据的，只能返回「未知」或「不适用」，不允许把模糊感觉写成「是」或「否」。

「是」只表示存在值得继续探索的偏离，不编码严重程度；「否」也不等于已排除该方向，只表示按当前判据未命中。

### 第四步与前三步的边界

- 第四步只读取已经形成的问题表征，不重新执行事实采样；
- 第三步 Current State（当前状态）描述事实状态，第四步 Operational State（运行状态）审查该状态是否异常或值得继续查；
- 第二步 Information Provenance（信息来源 / 信息溯源）与第四步 Input Source（输入来源）不是同一字段；
- 第一阶段输入贫乏可以继续运行，但「未知」与其他认识状态必须继续向后传播，不得在黑箱内部被补成确定事实。

### 原生工具

当前候选工具：[`通用归因候选生成标准 V0.2`](../02_原生工具/通用归因候选生成标准_V0.2.md)

截至 2026-11-07，纵向搜索域状态为：

1. **Input & Exposure（输入与暴露）**：主体暂时冻结；
2. **State, Integrity & Task Capability（运行状态、完整性与任务胜任能力）**：主体暂时冻结；
3. **Requirements, Design & Trade-offs（要求、设计与固有权衡）**：主体暂时冻结；
4. **Execution & Process（执行与流程）**：主体骨架成立，尚未最终冻结；
5. 原 **Spatiotemporal Coordination（时空协调）**：整体结构拆除；Time（时间）与 Space（空间）摘出挂起；
6. **Interface & Dependency（接口与依赖）**：本轮主体结构完成。接口仅保留 Physical Compatibility（物理兼容性）与 Interface Contract Compatibility（接口契约兼容性）；依赖命中后调用 R-004 的 Failure Independence / Shared Dependency / Coupling Mechanism 等既有结构；Propagation / Cascade（传播／级联）摘出挂起；
7. **Resource & Resilience（资源与韧性）**：本轮主体结构暂时冻结。仅保留 Resource（外部可用资源）与 Resilience（资源侧缓冲／备援抗扰动）；Capacity 分流至 Resource／01 Rate／03 Design Adequacy；Allocation 有无分流至 01 Place／04 Omission／02 Activation State，公平／合理残留挂起；余量并入 Resilience；恢复资源留给 Domain 09；瓶颈／争用不塞入本域；
8—12：**搁置（PARKED）**。原「待逐域重构」与「下一纵向位置 Domain 08」一并撤销。

**搁置的后果（必须写明，不许含糊）：**

- 第四步当前只能在 **01—07** 生成候选；
- **Domain 08 Information, Measurement & Model（信息、测量与模型）不覆盖**：信息缺失、陈旧、不可访问、测量错误、分类错误、语义／传递失真、模型／假设／表征错误，都没有对应搜索域；
- **09 Control, Barrier & Recovery（控制、屏障与恢复）、10 Change, Accumulation & Lifecycle（变化、积累与生命周期）、11 Incentive, Adaptation & Selection（激励、适应与选择）、12 Stochastic Realization & Irreducible Variation（随机实现与不可约变异）同样不覆盖**；
- 只落在 08—12 的问题，第四步必须走 **Taxonomy Gap（分类体系缺口）** 出口保留自由文本，或按第七步 **升级**；不得假装 01—07 已覆盖，也不得临场编造新域充数。

当前挂起池至少包括 Time、Space、Degradation / Fatigue（退化／疲劳）、Propagation / Cascade（传播／级联）、Allocation 公平／合理残留。整个工具仍是候选架构，不能宣称最终冻结。

### 仿生边界

七步法总体可以是 Biomimetic / Bio-inspired（仿生／生物启发）的，但仿生对象是可复用的认知功能，而不是把某一个人的习惯性排故顺序直接复制为机器规则。人的经验可以提供候选启发，机器化结构仍需根据对象类型、因果机制、可验证性和后续动作价值重新设计。

### 与第五步的边界

第四步回答的是：

> **接下来值得往哪里查？**

第五步才把这些方向转成可以执行的下一动作，例如 Probe（探测）、Intervention（干预）、Experiment / Trial（实验 / 试错）等。

## ⑤ 下一动作

> **当前版本继承 V-002 的稳定可用结构，尚未完成新一轮专项重构。**

### 定义

根据当前事实、候选探索方向、候选原因和目标，选择下一项探测、处置、优化、等待、暂停或其他必要行动。

这一节点被确认是七步法作为降级程序的核心输出节点：前面的工作最终应把混乱状态加工成一个**当前有资格执行、风险边界可控、还能获得反馈**的下一动作。

### 原生检查结构

- 结果
- 成本
- 风险
- 信息
- 余地

详见：[`../02_原生工具/下一动作五项.md`](../02_原生工具/下一动作五项.md)

## ⑥ 反馈

> **当前版本继承 V-002 的稳定可用结构，尚未完成新一轮专项重构。**

执行行动后记录：

1. **实际上做了什么；**
2. **实际上发生了什么；**
3. **判断因此怎样改变。**

反馈可以：

- 增强候选；
- 削弱候选；
- 淘汰候选；
- 产生新候选；
- 改变下一动作；
- 触发重新定界。

新结果重新进入事实采样与后续循环。

## ⑦ 退出 / 升级

### 定位

第七步保留，但它不是普通线性加工步骤，更接近 Control Node（控制节点） / State Transition Node（状态转换节点）。

它可以决定：

- **继续**：进入下一轮；
- **等待**：缺少时间、信息、资源或条件；
- **换路**：目标不变，但当前路线价值下降；
- **停止**：目标完成，或继续处理已无足够价值；
- **升级**：交给拥有更高权限、更多资源、更专业能力的主体；
- **重新定界**：目标、交换边界、关键事实或环境已经改变。

因此它既是“第七步”，也可能倒过来成为下一轮的入口控制器。

## 运行方式

七步法不是一条只跑一次的直线：

> **定界 → 事实采样 → 结构化 → 归因 → 下一动作 → 反馈 → 退出 / 升级 →（必要时循环）**

## 边界

- 处理不了可以返回无法处理；
- 「未知」是合法状态；
- 七步法不替代安全 / 审结层；
- 七步法不负责给高风险行动自动授权；
- 七步法不负责证明“现实一定正确”；
- 七步法不等于副躯体全部系统。
